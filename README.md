## 📌 Projects Overview

### 1. Number Guessing Game
* **Concepts:** `while` loop, `if-elif-else`, `break`, `continue`, `while-else`
* **Description:** A game where the computer picks a random secret number between 1 and 10, and the player gets 3 attempts to guess it.
* **Key Features:**
  * Uses `continue` to skip out-of-range inputs without deducting an attempt.
  * Uses `break` upon guessing correctly.
  * Employs `while-else` to handle running out of attempts.

---

### 2. Multiplication Table Generator
* **Concepts:** `for` loop, `range()` function, f-string formatting
* **Description:** Takes an integer input from the user and prints its complete multiplication table from 1 to 10 in standard `number x i = result` format.

---

### 3. Body Mass Index (BMI) Calculator
* **Concepts:** Custom Functions (`def`), Parameters, Return Values, Arithmetic Operators
* **Description:** A utility function `calculate_bmi(weight, height)` that computes a user's Body Mass Index using the formula $\text{BMI} = \frac{\text{weight}}{\text{height}^2}$.
